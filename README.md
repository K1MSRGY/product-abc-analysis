Excel project for product profitability and ABC analysis
# Product ABC Analysis

## Описание проекта

Excel-проект по анализу товарного ассортимента и прибыльности.

## Инструменты

- Microsoft Excel
- Формулы Excel
- ABC-анализ

## Задачи проекта

- Расчет прибыли по товарам
- Анализ выручки и финансовой значимости товаров
- Ранжирование товаров
- Расчет кумулятивного значения
- Расчет кумулятивной доли
- Классификация товаров по категориям A, B и C

## Использованные инструменты

- SUMIF
- SUMIFS
- COUNTIFS
- IF
- Ranking
- Cumulative Share
- ABC Analysis

## Результат

Проект позволяет определить товары, которые формируют основную часть финансового результата, и разделить ассортимент на категории A, B и C для дальнейшего анализа и принятия решений.
